## 🧩 Featured Projects

### NetWatch — Real-Time Network Anomaly Detection

Built a C++20 engine that processes optical network telemetry from three nodes and detects anomalies in latency, packet loss, jitter, and bit error rate.

- Used Linux `inotify` to ingest telemetry as files changed and rolling Z-scores to flag anomalies with thresholds tailored to each metric.
- Streamed alerts through a gRPC API, displayed them on a live dashboard, and packaged the application with Docker.

### NBA Stats Database

Built a relational SQLite database and a Python command-line interface for querying NBA statistics.

- Designed a schema that connects players, teams, games, and seasons.
- Added queries for looking up player performance across games and seasons.

### Concurrency Across Shared Memory

Built a C program on Linux that uses shared memory and semaphores to coordinate database access across multiple processes.

- Implemented synchronization to prevent deadlocks and livelocks.
- Tested concurrent reads and writes to verify mutual exclusion and check for race conditions.
